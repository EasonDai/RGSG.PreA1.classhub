# Pre A1 · Class Hub 班级平台

南京金地未来学校 · 国际高中 **Pre A1 班**的数字之家。
英式学院风（墨绿 × 香槟金，配色参照学校官网 rgsgnj.com），中英双语，纯静态网站。

## 🚀 快速开始

**方式一（推荐）**：直接双击 `index.html`，用浏览器打开即可 —— 无需安装任何东西。

**方式二**（体验更完整）：在项目目录运行本地服务器
```bash
python3 -m http.server 8000
```
浏览器访问 http://localhost:8000

## ✏️ 如何更新班级信息（最重要）

**所有班级信息都在 `js/data.js` 一个文件里**，改完保存、刷新浏览器即可看到效果，不需要动任何其他代码。

- 文件内每个字段都有中文注释和格式示例
- 空数组页面会显示"信息待录入"的友好提示，填入数据后自动展示
- 照片放入 `assets/` 文件夹，然后在 data.js 里填路径即可

### 📷 照片放在哪里

所有图片都放进 **`assets/` 文件夹**（访达里直接拖进去即可）。目前这些位置挂着占位图，替换成真实照片后告诉我们文件名，把 `js/data.js` 里的路径一行改掉即可：

| 用途 | 推荐文件名 | 现在挂的占位图 |
|---|---|---|
| 班级合照（首页） | ✅ 已接入 `class-photo.jpg` | —（占位图已替换） |
| 校徽 / 校标（页脚 · 浏览器标签页图标） | ✅ 已接入 `weibiaoti-12222.png` | —（占位图已替换） |
| 相册照片（新生周活动） | ✅ 已接入 `assets/新生周活动照片/照片1~5.jpg` | —（占位图已删除） |

真实照片保留任意文件名也可以（如微信保存的 `IMG_1234.JPG`），发给我们文件名即可接上。

### 信息清单速查

| 数据 | data.js 字段 | 说明 |
|---|---|---|
| 班级口号 / 班主任寄语 / 班规 | `classInfo` | 含学年开始日期 `termStart` |
| 班级合照 | `classInfo.photo` | 如 `"assets/class-photo.jpg"` |
| 课程表 | `timetable` | 周一~五每天 8 节：科目 + 老师 + 教室 |
| 老师 / 学生名单 | `members` | 含书院、职务、座右铭、生日 |
| 值日表 | `duty` | 周一到周五值日名单 |
| 倒计时大日子 | `events` | 名称 + 日期 + emoji |
| 班级公告 | `announcements` | 标题 + 日期 + 内容 + 紧急程度 |
| 班级角 | `classCorner` | 照片 + 标题（放 `assets/班级角/`） |
| 相册 | `gallery` + `tags` | 照片/占位图标 + 标题 + 日期 + 活动标签 |
| 作业截止 | `deadlines` | 用于首页"作业截止"卡片 |

## 📁 项目结构

```
├── index.html          首页（今日一览 / 倒计时 / 快讯 / 班级角）
├── timetable.html      课程表（点击课程看详情）
├── members.html        班级成员（书院筛选 / 档案弹窗）
├── gallery.html        活动相册（时间线 / 灯箱）
├── css/style.css       设计系统（配色 / 组件 / 响应式 / 深色模式）
├── js/
│   ├── i18n.js         中英双语词典
│   ├── data.js         ★ 班级数据（唯一需要编辑的文件）
│   ├── main.js         公共交互（导航 / 主题 / 动效）
│   ├── home.js         首页逻辑
│   ├── timetable.js    课程表逻辑
│   ├── members.js      成员页逻辑
│   └── gallery.js      相册页逻辑
└── assets/             Logo、图标、照片
```

## 🎨 设计系统

- **品牌色**：墨绿 `#004130` × 香槟金 `#CFAE78`（配色参照学校官网 rgsgnj.com）
- **校徽标识**：导航栏 / 抽屉 / 页脚 / 浏览器标签页均使用学校校徽（`assets/weibiaoti-12222.png`）；首页英雄区水印使用 `assets/背景图logo.png`；相册封面 / 灯箱水印为校徽淡影
- **四大书院**：奥斯汀 `#B03A3A` / 白金汉 `#3E6BD0` / 哈蒙德 `#3E8E5A` / 瓦尔皮 `#FFFFFF`（白色书院已做对比度处理）
- **双语**：右上角 EN / 中文 一键切换，记忆选择
- **深色模式**：🌙 按钮切换，自动记忆
- **响应式**：桌面 / 平板 / 手机三档
- **无障碍**：焦点样式、键盘操作（灯箱 ← → Esc）、减少动效支持

## 🌐 部署上线（免费）

**GitHub Pages**：把整个文件夹推到 GitHub 仓库 → Settings → Pages → 选 main 分支 → 得到 `https://你的用户名.github.io/仓库名/` 链接。

**Vercel / Netlify**：注册后拖拽文件夹上传即可，自动生成链接。
