## 📋 待班级提供的信息清单

### 信息类（填入 js/data.js）

1. **班级基本信息**：班级口号/班训、人数、班主任姓名、班主任寄语、班规、学年开始日期
2. **学生名单**（每人一行）：
   中文名 + 英文名 + 书院（austen / beckingham / hamonde / valpy）+ 职务 + 座右铭 + 生日（MM-DD）
   ✅ 已收到姓名；待补：4 位同学英文名（盛文辰 / 黄箬心 / 王伟杰 / 窦金苗）、每人所属书院、生日、职务、座右铭
3. **教师名单**：姓名（中/英）+ 科目 + 职务（班主任填 "homeroom"）
4. **课程表**：周一~周五每天 8 节，每节 = 科目 + 老师 + 教室（拍照发我也可）
5. **值日表**：周一~周五值日安排
6. **重要日期**：开学/运动会/期中考试/研学/假期等（名称 + 日期，用于倒计时）
7. **班级公告**：最近通知（标题 + 日期 + 内容 + 紧急程度）
8. **班级荣誉**：奖项名称 + 时间
9. **活动照片清单**：照片 + 活动名 + 日期 + 参与人
